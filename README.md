# Cut---bot

24x7 Telegram group AI social bot.

Core:
- Telegram bot runtime on a cloud server
- Gemini-powered natural conversation
- SQLite memory on the server
- NO_REPLY when the bot should stay quiet
- explicit AI identity
- fictional Uttarakhand/Hindu/Mahadev/anime/B.Com character lore
- age-appropriate, non-romantic/non-sexual behaviour

Planned modules:
- Telegram sticker catalogue and safe sticker library
- reactions
- member profiles and birthdays
- games
- proactive GM/GN and quiet-group scheduler
- admin-aware moderation
- Telegram media storage/file IDs

Secrets must be supplied through server environment variables, never committed to Git.
